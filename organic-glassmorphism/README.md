# Organic Glassmorphism WordPress Plugin

A WordPress plugin that applies a beautiful, organic glassmorphism design system across your entire website. Inspired by Apple's design principles but reimagined with a warm, natural color palette.

## Description

This plugin brings the beautiful depth and vibrancy of glassmorphism to your WordPress site, but with a unique, organic twist. Instead of the typical cool, blueish tones, this plugin uses a palette of warm, natural colors—think rich browns, soft creams, and the gentle glow of incandescent light. It's designed to be lightweight, theme-agnostic, and highly customizable, giving your site a modern, cohesive, and professional feel without needing page builders.

The plugin is built to enterprise-level standards, featuring an object-oriented architecture, adherence to WordPress coding standards, and a focus on security and performance.

## Features

- **Site-Wide Glassmorphism:** Automatically applies the glass effect to your theme's main content area.
- **Theme-Agnostic:** Works with most WordPress themes out of the box by targeting common content selectors. Includes a filter for developers to add compatibility for any theme.
- **`.glass-card` Component:** Easily highlight content by adding the `glass-card` CSS class to any element.
- **Advanced SVG Filters:** A subtle, liquid-like distortion is applied to the glass effect for a premium, dynamic feel.
- **Dark/Normal Mode Toggle:** A persistent, user-facing toggle in the footer allows visitors to choose their preferred viewing experience.
- **Admin Control Panel:** Fine-tune the effect's transparency from a simple settings page.
- **Developer Friendly:** Built with best practices, including a filter-based approach for extending functionality.

## Installation

1. Download the latest `.zip` file of the plugin from the [Releases](https://example.com/) page.
2. In your WordPress admin dashboard, navigate to **Plugins > Add New**.
3. Click **Upload Plugin** and select the downloaded `.zip` file.
4. Activate the plugin after it has been installed.
5. The glassmorphism effect is now active! You can customize its settings by navigating to **Settings > Organic Glassmorphism**.
